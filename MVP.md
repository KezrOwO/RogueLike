# MVP Jouable

## ✅ Ce que le MVP doit contenir 

- Déplacement joueur 
- Tir de projectiles
- 1 Type d'ennemie
- 2-3 salles enchainées
- Mort du joueur 
- Fin de run 

**Notes** : Sans items, sans boss, sans polish.

---
## 📅 Planing du MVP 

### Première itération

- Setup projet
- Joueur + déplacement 
### Deuxième itération 

- Attaque + projectiles
- Dégâts

### Troisième itération 

- Ennemi simple
- Combat fonctionnel
- Système de PV / mort


### Quatrième itération 

- Salles + transitions

### Cinquième itération 

- Nettoyage
- Bugs
- Refacto légère

### Sixième itération 

- Build jouable
